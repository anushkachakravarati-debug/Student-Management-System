Student Management System

A Python-based Student Management System that allows users to manage student records through a menu-driven program.

Features

- Add new student records
- View all students
- Search students by roll number
- Update student details
- Delete student records
- Save student data to a text file
- Load previously saved records using file handling
- Handle invalid inputs using exception handling

Technologies Used

- Python
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling

Concepts Used

- Classes and Objects
- Constructors ("__init__")
- Special Method ("__str__")
- Lists
- Loops and Conditional Statements
- Try-Except Blocks
- Reading and Writing Files

Purpose

This project was developed to practice Python programming, OOP, and file handling by building a practical student record management application.
